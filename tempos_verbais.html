Tempos Verbais

Todos os tempos verbais italianos

Tempo Verbale Struttura / Formula Uso Principale Esempio
Presente Radice + desinenze Azione attuale / abitudini Lei prepara la cena ogni giorno.
Imperfetto Radice + -vo, -vi, -va, -vamo… Descrizione / abitudine nel passato Quando ero bambino, preparava la cena.
Passato Prossimo Avere / Essere + participio passato Azione conclusa nel passato Ha preparato la cena ieri.
Trapassato Prossimo Avere / Essere all'imperfetto + participio Passato del passato Aveva già preparato la cena.
Futuro Semplice Radice + -ò, -ai, -à, -emo… Futuro / ipotesi Preparerà la cena domani.
Condizionale Presente Radice del futuro + -ei, -esti… Desiderio / ipotesi Preparerebbe la cena se avesse tempo.
Gerundio Radice + -ando / -endo Azione simultanea Parla preparando la cena.

🎯 Dicas de Uso

  • Passato Prossimo vs Imperfetto: Use passato prossimo para ações concluídas, imperfetto para descrições e hábitos passados
  • Futuro Semplice: Também usado para fazer suposições no presente ("Dove sarà?" = "Onde estará?")
  • Condizionale: Essencial para fazer pedidos educados ("Vorrei un caffè" = "Gostaria de um café")
  • Gerundio: Muito comum para indicar duas ações simultâneas ("Studio ascoltando musica")
